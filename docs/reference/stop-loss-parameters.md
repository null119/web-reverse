## 难度分档（所有阈值的前置语义）

部分任务（长链路、复杂结构、多未知项叠加）是**长积累、突发收益**的认知曲线——与通用任务「每 1~2 轮应产出新认知」的阈值标定不匹配。解法是**分档**而非全局放宽：上限管的是低效硬顶不是难，深任务档放大预算，宏观停损与「有效推进」判定照常工作，防止预算放大退化成无限消耗。

- 分档依据任务特征自查自定：`standard`（标准，缺省）/ `deep`（深任务）。
- 早判定命中复杂结构、多依赖叠加时，按深任务档预算执行。

### 分档参数表

| 参数 | standard（标准） | deep（深任务） |
|------|---------|--------------------|
| 同疑点验证上限 | 3 | 6 |
| 同族取证无证据上限 | 2 轮 | 4 轮 |
| 基建期连续无新增 pivot | 2 轮 | 3 轮 |
| 基建期进不了验证期 → 强制复盘 | 4 轮 | 16 轮 |
| 深挖期默认 maxRounds | 5 | 12 |
| 深挖期连续无产出退出 | 2 轮 | 3 轮 |
| 宏观停损（连续无推进） | 2 轮 | 3 轮 |

达同疑点上限的合法出路（按正当性排序）：
1. **真 pivot**：结构性换线。
2. **EXHAUSTED 声明**：该路线被证据结构性否定，明确搁置。
3. **换新疑点**：真正不同的疑点（措辞微调绕计数是自欺）。
4. **renewal（深任务档免费 2 次）**：续行必须说明**本次失败以不同方式证伪**。
5. 无理由续行 = grind 合谋，自己叫停。

## 搁置语义：PARKED-EXPENSIVE ≠ EXHAUSTED-DEAD

- `EXHAUSTED-DEAD`：该路线被证据**结构性否定**（关键判据被证伪、前置条件不存在）。
- `PARKED-EXPENSIVE`：该路线**可行但成本高**，当前性价比不足。
- **便宜路线失败 → 强制重审 parked 路线**：当更便宜的路线（直接复用 → 边界复用 → 集成环境内复用 → 本地重建）因**结构性原因**失败（有具体失败证据，非"没试好"），重审全部 `PARKED-EXPENSIVE` 路线。这条堵住"贵路线被过早收敛 → 便宜路线全灭 → 项目无法推进"的死循环。

## 停损轮次（按阶段）

| 阶段 | 任务特征 | 停损轮次 |
|------|---------|---------|
| **基建期（通用）** | 观测与取证基础、关键链路定位 | 连续 2 轮无新增基础产出 → pivot；连续 4 轮无法进入验证期 → 强制复盘 |
| **基建期（深任务）** | 复杂结构枚举、多依赖追踪 | 标准 8 轮 / 深任务 16 轮无法进入验证期 → 复盘；连续无新增产出的 pivot 阈值分档（2 / 3 轮） |
| **验证期** | 已有基础设施，做具体假设验证 | 连续 2 轮无新增验收证据 → pivot 或复盘 |
| **深挖期** | 高成本微路线（自定 permit：maxRounds / exitCondition） | 标准 5 / 深任务 12 轮上限；连续 2~3 轮无产出退出 |

## 验证期冷却期

基建期 → 验证期升级后的**第一轮**为"验证期第 0 轮"（观察轮），不计入验证期的 2 轮停损；发现基建不完整允许降回补充。基建→验证循环最多 **2 次**，第 2 次从观察轮降回后必须切换主路线或复盘。

## 降级缓冲

降级后在新梯度至少执行 **3 轮**才能再次降级（适应期不触发停损 pivot，但仍需有效推进）；连续两次"提前降级"= 该触发复盘了。降级时想清楚：为什么当前梯度太高（具体证据）、哪些高成本路线被暂停（不是放弃）、降级后的最小交付目标。

## 阶段回退协议

允许从高阶段主动回退到低阶段，保留已建立的基础设施：

| 回退触发条件 | 回退路径 | 保留内容 |
|-------------|---------|---------|
| 基建不完整（观测空转、链路断裂） | 验证期 → 基建期 | 已建立的观测脚本、取证日志、入口评估 |
| 关键未知项仍在会话态/生命周期，不是实现边界 | 本地重建 → 集成环境内复用 | 已完成的实现片段、边界映射 |
| 连续 2 轮验证无证据 + 交付梯度与验收目标不匹配 | 当前梯度 → 下一低梯度 | 所有已验证的链路与证据 |
| 深挖路线成本超过对最终交付增益的 2 倍估算 | 深挖期 → 验证期 | 路线映射、高价值证据记录 |

回退纪律：回退不是"放弃"，是"换一条更便宜的路"；回退后想清楚原因、保留内容、回退后的第一条验证动作。

## 深挖许可（自查五字段）

深挖属于高成本路线，进入前自问并写进工作笔记：

| 字段 | 含义 |
|------|------|
| `subgoal` | 本次深挖要解决的具体子目标 |
| `milestone` | 可观测里程碑 |
| `maxRounds` | 本微路线轮次上限（标准 5 / 深任务 12） |
| `exitCondition` | 退出条件（达成 / 超轮 / 连续无产出） |
| `expectedHighValueEvidence` | 预期的高价值证据形态 |

permit 结束（达成、超轮、或连续 2 轮无高价值证据）后，**回退到上一可验收层**，并复盘重选入口，**不要在原微路线硬顶**。

## 「有效推进」判定（区分新线索 vs 同一失败的新变体）

停损计数的关键是判定每轮是否**有效推进**——不是"有没有产出动作 / 新脚本 / 新数字"，而是"是否真的逼近验收"。以下统一归入**不算有效推进**：

- 更细的内部解释、更多同层低价值取证、只在环境差异上细化但不逼近交付
- **换实现、换库、调参但验收边界未移动的迭代**（端到端结果仍为失败），按**同一失败的新变体**计。判据：产物内容变了，但端到端结果仍为失败

反之，"结构化积累真实增长"（映射表、清单、日志的实质扩充并服务于验收）**算推进**——长积累期不会被误判为零推进，这是分档放大敢放开的前提。
